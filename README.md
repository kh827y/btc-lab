# BTC Lab

Личный проект исследования рынка BTC. Первый модуль — локальная BTC Market Panel v2.

## Начало работы
1. Установить Git for Windows и Python 3.11+.
2. Клонировать этот приватный репозиторий.
3. Один раз выполнить import_panel.bat, если панель ещё не перенесена. Он берёт только исходный код и документацию из соседней папки btc-market-panel и отправляет их в этот репозиторий.
4. После переноса запускать start_windows.bat. Перед очередным обновлением закрыть панель и запустить update.bat (git pull --ff-only).

## Принципы
- Существующий публичный btc-market-data продолжает работать отдельно. Панель читает его brief.json.
- Приватные ключи, локальные кэши и большие исторические архивы не хранятся в Git.
- Исследования добавляются постепенно; готовые библиотеки предпочтительнее собственного сложного кода.
- ARCHITECTURE.md, AGENTS.md и PANEL_README.md будут перенесены вместе с панелью; архитектуру расширяем по мере разработки.
