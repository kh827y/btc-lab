# BTC-Lab — единый план (27.11.2026)

Цель — проверяемые знания для позиционного инвестора BTC (недели–месяцы), прежде всего влияние новостей, ожиданий и состояния рынка. Не автоторговля.

1. **Готово:** локальная панель и часть истории, протокол CPI, реальный архив 106 релизов (105 месячных сюрпризов), сравнительные тесты моделей и API. CPI хранится локально, лицензии прогнозов неоднородны. Не пересобирать архив и не повторять бенчмарки.
2. **Сейчас:** загрузчик минут Binance BTCUSDT spot с 2017-08-17, проверка SHA-256, временных границ, OHLC, пропусков; локальный запуск и аудит фактического покрытия. Сохранить прежний дневной источник; сверить цены в исследовании.
3. **Далее:** импорт CPI и точное объединение по UTC; зафиксировать протокол до просмотра результата, включая альтернативные прогнозы, нестандартные релизы, календарь сопутствующих событий, train/development/test, комиссии. Программные функции для расчётов, воспроизводимый отчёт и журнал гипотез. Отрицательный/неопределённый результат допустим.
4. **Первый агентный цикл:** переиспользовать проверенные части сетевого harness; минимальный локальный Python-контроллер, ограниченные read-only инструменты, проверяемые расчёты, сохранение попыток/артефактов и бюджета. Один реальный CPI-эксперимент, тесты с имитацией сбоев и малый API smoke-test, а не повтор бенчмарков. Никакого произвольного shell или исполнения кода LLM.
5. **Astra:** независимый научный аудит первого исследования, затем сложная методология и значимые спорные результаты. По запросу владельца отдельное исследование внеплановых криптоновостей может идти параллельно, если ещё не выполнено.
6. **Масштабирование после сквозной проверки:** небольшая серия гипотез, оценка реальной стоимости, завершённости и качества; дедупликация, контроль множественных проверок, независимая проверка, сохранение отрицательных результатов. Не строить инфраструктуру для тысяч работ заранее.
7. **Расширение:** ФРС/ETF, криптособытия, индикаторы и их сочетания; внедрять только проверенные полезные результаты. Действующий мониторинг не менять без отдельного решения.

## Модели и безопасность
CheapVibeCode — основной, DeepSeek V4.1 Flash 1017 High; Max при сложной задаче. Sol High руководит по необходимости, MiniMax резерв/независимый взгляд. Surplus/Mistral — испытанный резерв DeepSeek. Astra (Work) — научная методология, сложные решения и аудит, с передачей задания владельцем. Не применять Opus/Fable как критический аудитор без подтверждения маршрута. Не искать новые API без реальной необходимости.

Локальная программа считает числа, проверяет доступность данных, управляет лимитами и повторениями; модели формулируют гипотезы и оценивают смысл. Никаких прав на произвольные команды, секреты, GitHub, диск или сеть для внешних работников; инструменты только из белого списка. Учитывать расход, неизвестный usage и надбавку поставщика; не обходить тарификацию. GitHub + update.bat, без Google Drive для разработки.
