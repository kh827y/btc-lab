# GATE-001 — synthetic risk detection diagnostic (registered before run)

Purpose: identify whether the old rolling ridge method can detect a useful risk signal when known to exist, with overlapping four-week outcomes and persistent regimes. This is a first local gate diagnostic, NOT the final study-specific OI gate, nor a reproduction of Fable's exact unpublished simulation. No actual prices, no decision optimization. Use 128 independent histories per scenario, seeds 2026112801..04, 110 warmup weeks, nested 86 and 150 evaluation origins, four future weekly returns. Synthetic observed regime binary symmetric Markov switch .04/week; independent latent signal +/-1 symmetric switch .15/week. Weekly log returns either log(.88) or log(1.08); probability down=.25+.30*regime+effect*signal. Effects fixed 0 (independent calibration/validation), .10 moderate and .20 strong. Label min cumulative log return over four weeks <=log(.85), includes endpoint, no intraday lows. Predict before week t with current regime and trailing four realized returns; challenger adds current signal. Rolling104 min52 matured labels, latest train t-4; fixed standardized ridge logistic identical objective and 300-step solver to BUY, batched for numerical speed, parity test. No future states or target in fit. Compare Brier baseline minus challenger, positive better. Exact known-process oracle with current signal vs filtered oracle without signal (Bayes filter using past returns and observed regimes), expected gain squared probability difference, realized gain secondary positive control. Synthetic regime observed, not a claim real BTC regimes are known.

Minimum absolute Brier gain .01 diagnostic engineering choice, NOT investor tolerance or portfolio utility. Fixed threshold max(.01, 90th percentile of independent calibration-null per-history mean gain) per sample size. Evaluate independent validation null, moderate and strong, report all per-history scores, detection fraction and 95% Wilson Monte Carlo intervals. Point pass: moderate oracle expected gain >=.01 AND independent null detection <=10% AND moderate detection >=80%. Uncertainty-qualified pass additionally Wilson upper null <=10%, lower moderate >=80%. Strong effect sensitivity only, cannot rescue failed moderate gate. No choosing seeds, parameters, thresholds or winning sample after seeing output. If moderate oracle gain <.01, positive control too weak for criterion, gate inconclusive/fail, not proof no power. Threshold is simulation-specific; never use as market significance test. Even success only diagnostic under stylized model; final OI gate needs actual chosen price-only reference, full real target cadence and sample assumptions, no opening new outcomes until separate registration. Decision-leverage gate deferred until decision and meaningful tradeoff specified. No LLM calls, no new data, one local run, preserve report.
