# BTC Market Panel — локальная визуальная панель

Приложение **только показывает** данные существующего агрегатора из `kh827y/btc-market-data`. Оно не меняет сборщик, не использует API нейросетей и не совершает сделок.

## Запуск на Windows

1. Установите Python 3.11 или новее с [python.org](https://www.python.org/downloads/) (при установке включите **Add Python to PATH**, если предлагается).
2. Распакуйте ZIP-архив в любую папку.
3. Дважды нажмите **`start_windows.bat`**. При первом запуске понадобится интернет: Python установит бесплатные зависимости.
4. Откройте адрес **http://127.0.0.1:8501** в браузере (обычно он откроется автоматически).
5. Для остановки закройте окно консоли или нажмите в нём `Ctrl+C`.

Все следующие запуски выполняются тем же `start_windows.bat`. Файл не устанавливает системные службы и не меняет репозиторий.

## Другие платформы и ручной запуск

## Как работает

- По умолчанию раз в несколько минут читает публичный [brief.json](https://raw.githubusercontent.com/kh827y/btc-market-data/main/btc-monitor/data/brief.json).
- При успешной загрузке сохраняет копию в `data/last_good.json`. При сетевой ошибке показывает её **с явным предупреждением**, без выдачи старых чисел за актуальные.
- Можно переключиться на локальный JSON в левом меню.
- Использует `metric_quality.checks` и собственные статусы источников. **Неполные, устаревшие, некорректные или отсутствующие значения не превращаются в ноль.** Для CVD исходная пятёрка бирж не подменяется альтернативным набором.
- Не строит исторические графики из одного снимка: для них позже подключается настоящий архив.
- Цена — Binance Spot BTCUSDT; многие другие метрики имеют отличающиеся моменты обновления. В каждом блоке учитывайте дату и статус.

## Разделы

«Обзор», «Цена и тренд» (с картой уровней), «Спрос и ETF», «Деривативы», «Опционы и ончейн», «Макро», «Стаканы» и «Качество данных».

## Настройки

В начале `app.py` есть блок настроек: часовой пояс отображения (`LOCAL_TZ_NAME`, по умолчанию `Asia/Tomsk`) и частота обновления экрана (`REFRESH_SECONDS`).

## Как читать карточку

- Зелёная точка — значение прошло проверку качества агрегатора.
- Оранжевая точка и серое «—» — значение устарело, неполное или отсутствует. Причина указана под числом или во всплывающей подсказке.
- Внизу карточки — когда измерено значение (по местному времени), а не когда скачан файл.
- Производные числа («цена относительно MA200», среднее funding) считаются, только если все исходные значения проверены.

## Ограничения

- История свечей, полноценные графики изменения CVD/OI и новости ещё не подключены.
- `brief.json` — моментальный срез с разновременными метриками; свежий файл не гарантирует свежесть каждой метрики.
- Доступность бесплатных источников может измениться. Панель следует правилам качества текущего агрегатора, не заменяя независимый аудит данных.
- При первом старте необходимо соединение с интернетом и свободные пакеты Python. Для постоянной работы достаточно локального ПК.
- Статусы и значения агрегатора показываются как есть; это информационная панель, а не инвестиционная рекомендация.
