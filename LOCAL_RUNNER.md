# BTC-Lab: облачные проверки и Brave (без Docker)

Актуальная схема заменяет прежний Docker-пилот. Новый исследовательский код автоматически выполняется только на GitHub-hosted runners. Фиксированный локальный Python-ретранслятор читает статусы GitHub и передаёт события расширению Brave; он не запускает скачанный код, shell, git pull, bat или произвольные команды. Не требует Docker, WSL, дополнительных Python-пакетов или прав администратора. Все файлы ретранслятора и отчётов на ПК — внутри D:\Проекты\btc-lab; браузер хранит собственные служебные настройки. Задачи с приватными локальными архивами или недоступными из облака API пока требуют отдельного решения и согласования. Не выдавать отсутствие данных за успешную проверку.

## Одноразовая настройка
1. Приватный репозиторий kh827y/btc-lab-bridge уже создан с main и README, доступ ChatGPT проверен. Не делать публичным. Fine-grained PAT только для этого репозитория: Contents Read and write, Metadata read; ограниченный срок. Не добавлять другие разрешения. https://github.com/settings/personal-access-tokens/new
2. Отдельный бот Telegram уже создан. Токен и GitHub PAT вводить только локально, не в чат.
3. Один раз запустить update.bat, затем setup_local_runner.bat в D:\Проекты\btc-lab. Ввести kh827y/btc-lab-bridge, PAT и токен Telegram. Отправить выданную одноразовую строку /start ... своему боту в личной переписке, нажать Enter. Сохранить локальный pairing key. Если возникла ошибка, сообщить только текст ошибки без ключей; не удалять файлы при частичной установке.
4. В Brave открыть brave://extensions → Developer mode → Load unpacked → D:\Проекты\btc-lab\data\local_runner\browser_bridge. Открыть именно чат BTC-Lab, нажать иконку расширения, вставить pairing key, выбрать «Привязать текущий чат и включить».
5. Запустить data\local_runner\start.bat, оставить окно и вкладку открытыми. Сообщить «готово». До проверки доставки результата именно в этот чат не оставлять без наблюдения. Автозапуск Windows не установлен. Ctrl+C останавливает ретранслятор, «Остановить» выключает расширение. Не отправлять ключи помощнику.

## Протокол
- Только задача market_state. Для запуска помощник создаёт/обновляет публичный cloud_job.json в main kh827y/btc-lab с полями id (уникальный ASCII <=64), task (market_state). Коммит запускает market_state_check.yml, GitHub-hosted ubuntu, read-only token, без приватных данных и ключей, timeout 6 min. Workflow печатает только отчёт публичных рыночных данных между BTC_LAB_REPORT_BEGIN/END, сохраняет artifact 3 дня. Ошибка API может означать неполный пакет, даже если workflow success. Помощник проверяет отдельные статусы/ошибки, а не только conclusion.
- В приватном mailbox job.json ровно id, commit (точный 40-символьный SHA коммита cloud_job.json), task. Локальный ретранслятор раз в 90 секунд ищет завершённый push run именно фиксированного workflow на main и данном SHA, сохраняет immutable results/<id>.json с run_id, conclusion, статусом и ссылкой. Никакого скачивания/исполнения кода на ПК. Помощник читает файл и реальные логи/артефакт через GitHub. Один job за раз, следующий ID только после анализа предыдущего.
- progress.json в PRIVATE mailbox: ровно id (unique ASCII <=55), kind (progress или attention), text (одна строка <=200 символов). progress → 🔧 короткая стадия; attention → 🚨❗ запрос участия, дальнейшие задания приостанавливаются до явного ответа владельца и замены progress.json. Не отправлять обычные старты/результаты/исправимые ошибки; только существенный этап и реальная необходимость вмешательства. Одноразовый тест Telegram при настройке. Telegram не принимает команды.
- Локальные контроллер/relay/extension копируются один раз под ignored data/local_runner и не обновляются автоматически; PAT и bot token защищены DPAPI текущего пользователя, pairing key локальный. Никаких shell/remote code/subprocess. HTTP loopback 127.0.0.1:18746 с ключом, next/claim/ack. Ограниченные пути и размеры, без перезаписи существующих результатов.
- Brave только явно выбранная вкладка/URL, не читает ответы модели и историю, обычный composer и кнопка отправки, без обхода лимитов, смены модели, автоматических повторов неопределённой отправки; пилот максимум 20 отправок на одно ручное включение. Неофициальная интеграция, может перестать работать. Если не разрешена или интерфейс несовместим, остановить и продолжать вручную. При блокировке/неподтверждённой отправке или долгом ожидании — attention. Никаких Codex/API моделей/ChatGPT Tasks/swarm. Правила https://openai.com/policies/terms-of-use/.
- Помощник обрабатывает результат, проверяет CI, записывает ROADMAP и ставит следующее допустимое задание. Не менять frozen journals/monitor, не открывать незарегистрированные исследования. При новых разрешениях, локальных архивах, запросах Fable/Opus/Astra — attention, никаких дополнительных агентов. Fable/Opus prompts/reports English.
