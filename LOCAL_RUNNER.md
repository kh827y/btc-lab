# BTC-Lab: локальный исполнитель и Brave (пилот)

## Одноразовая настройка владельцем
1. Установить и запустить Docker Desktop (Linux containers, default installation): https://docs.docker.com/desktop/setup/install/windows-install/ . Не предоставлять доступ к другим каталогам. Программы проекта и отчёты сохраняются в D:\Проекты\btc-lab; Docker/WSL и Brave хранят свои служебные данные в собственных каталогах ОС. Изоляция контейнера снижает риск, не является абсолютной защитой; bridge network разрешает исходящий интернет и потенциально доступ к сетевым службам хоста.
2. Создать отдельный PRIVATE репозиторий **kh827y/btc-lab-bridge** с README и веткой main (https://github.com/new). НЕ использовать публичный BTC-Lab или временное зеркало Hoplite. Разрешить подключённому ChatGPT GitHub app читать и писать этот репозиторий. Не делать публичным.
3. Создать fine-grained PAT (https://github.com/settings/personal-access-tokens/new): Only select repositories → только btc-lab-bridge; Contents Read and write; Metadata read автоматически. Ограниченный срок (например 30 дней); никаких Actions, Administration, других репозиториев. Токен вводить локально, не в чат.
4. Создать отдельного Telegram-бота через https://t.me/BotFather командой /newbot. Сохранить токен локально. Setup попросит токен и выдаст одноразовую строку /start ...; отправить её своему боту в личной переписке, затем Enter. Не передавать токен или pairing key помощнику.
5. Закрыть панель, один раз запустить update.bat, затем setup_local_runner.bat. Ввести имя репозитория, PAT, токен Telegram, подтвердить личный чат. Если ошибка — прислать только текст ошибки без ключей. Не удалять вручную файлы при частично выполненной установке.
6. В Brave открыть brave://extensions → Developer mode → Load unpacked → D:\Проекты\btc-lab\data\local_runner\browser_bridge (НЕ папка исходников в Git). Открыть именно чат BTC-Lab, нажать иконку расширения, вставить локальный pairing key из setup и «Привязать текущий чат и включить».
7. Запустить data\local_runner\start.bat; оставить окно и вкладку открытыми. Сообщить помощнику «готово» без ключей. Проверяем один реальный market_state job, доставку JSON/ошибки, Telegram и поступление нового сообщения в тот же чат. Не оставлять без наблюдения до успешной проверки. Setup не регистрирует автозапуск в Windows.

## Безопасность и протокол
- Fixed controller/relay/extension копируются один раз под data/local_runner, игнорируются Git. Не обновляются автоматически. Никаких git pull, shell, аргументов от удалённого задания, доступа к архивам, API-ключам или исходной рабочей копии для запускаемого кода. Только три исходных файла market_state.py, data_logic.py, live_derivatives.py с точного SHA предка main kh827y/btc-lab. Исходники read-only, Docker без привилегий/root/host mounts/сокета Docker, временная scratch FS, ограничение памяти/CPU/процессов/времени. Код программы имеет исходящий интернет, поэтому не обещать абсолютную защиту и не запускать непроверенные изменения агента. Никаких destructive cleanup; автоматическое удаление только своего временного контейнера. Windows-код setup/listener должен быть проверен владельцем перед первым запуском.
- Mailbox job.json: ровно id (unique ASCII, максимум 64), commit (40 lowercase hex), task ("market_state"). Один job за раз. Результат results/<id>.json immutable, статус ok/error/interrupted, версия, commit, report и SHA либо ограниченная ошибка. Полные исходные ответы локально, только выбранный отчёт и ограниченный контейнерный лог (публичные рыночные данные) возвращаются в PRIVATE mailbox. После создания результата не использовать тот же ID повторно; новый ID для нового запуска. Сверять точный SHA и происхождение. Не передавать секреты, локальную историю, позиции, данные других исследований.
- progress.json: ровно id (unique ASCII <=55), kind ("progress" или "attention"), text (одна строка <=200 символов). Создавать/заменять в mailbox, не в основном repo. progress → 🔧 короткая стадия; attention → 🚨❗ сообщение, новые задания приостанавливаются, пока владелец явно не даст продолжить и помощник не заменит progress.json. Текущий запуск не прерывается автоматически. Уведомления о старте/результате также автоматические. Telegram не принимает команды. При неопределённой доставке не повторять автоматически.
- Loopback HTTP 127.0.0.1:18746 с случайным локальным ключом, только next/claim/ack. Extension не читает ответы модели и историю, только состояние composer, использует обычную кнопку отправки для одного события; только явно выбранный URL/вкладка, не открывает другие чаты. Не изменяет модели, не обходит ограничения/капчи, не повторяет неопределённую отправку, максимум 20 подтверждённых попыток на одно ручное включение. Нет гарантии доставки или выбора модели. При ограничении/блокировке/ошибке остановиться, уведомить владельца, никаких обходов. Проверить правила https://openai.com/policies/terms-of-use/ . Это не официальный API ChatGPT; может перестать работать. Если автоматизация не разрешена или интерфейс несовместим, использовать только ручное продолжение.
- Stop: в Brave расширение «Остановить», в окне runner Ctrl+C (остановка своего контейнера при прерывании); при необходимости revoke PAT и токен BotFather. Не предоставлять доступ к другому коду, операциям, архивам, разрешениям или секретам без отдельного согласия. Никаких дополнительных ИИ, Codex, API, Tasks ChatGPT или swarm. Нет автоматического исполнения файлов из браузера. 
- Помощник: после результата обработать его, проверить CI, обновить ROADMAP и лишь затем создать следующий допустимый job; progress коротко перед началом существенного этапа. При необходимости мнения/внешней модели, новых разрешений или явного сбоя, отправить attention и остановить развитие, при необходимости дать английский prompt Fable/Opus. Не запускать незарегистрированные исследования или изменять BUY/RISK/monitor. Никаких тестов, требующих архивов, до отдельной безопасной установки.
