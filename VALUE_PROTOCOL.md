# VALUE-001 — MVRV (до расчёта)

Гипотеза: оценка цены относительно realized cost basis даёт дополнительную информацию о движении BTC на недели–месяцы. MVRV = market cap / realized cap; не фундаментальная оценка справедливой стоимости, включает цену. Kote Charts, локальный data/extended/kote-mvrv.json, атрибуция https://kotecharts.com/c/mvrv, методология https://kotecharts.com/methodology, docs https://kotecharts.com/docs. Дневные valuation данные по документации закрываются примерно через час после полуночи UTC; существующий архив ретроспективный, публикации/ревизии старых значений не доказаны, поэтому результат reconstruction only. Без нового запроса с ключом; при отсутствии архива сообщить. Проверить source identity, положительные finite значения, даты, coverage 2014–2023 >=95%, сохранить локальный snapshot/hashes. Не заполнять пропуски. Вычислять только до 2024.

Monday origin, Sunday cutoff, последняя цена Saturday close; log MVRV Friday (t−3 days), один полный день дополнительного лага. Sensitivity t−8 days на общих датах, не выбор лага. 2019-01-07..2023, полные 28/90d исходы, Bitstamp primary, Coinbase проверка цены (одни эпизоды/ончейн). Rolling 156 завершённых недель, минимум104, длиннее FLOW из-за медленного valuation фактора и 90d цели; одинаковый набор дат для всех моделей. Те же BUY features/logistic/outcome, L1 vs L1+log MVRV primary Brier direction 90d, 28d/risk≥15%/M2 vs M2+value secondary; frequency, .5 baseline, log score, годы. 52w conditional descriptive intervals, 13/26 sensitivity (не тест значимости; 90d перекрытие сильное). Отдельно фиксированные группы MVRV <1, 1..2.5, >=2.5: частоты, средняя/медианная/5th percentile будущей доходности, риск; не торговое правило, малые группы не интерпретировать как независимые циклы. Не выбирать лучшие пороги, лаги или горизонт. Никаких платных вызовов или правок BUY/CPI frozen files. 2024+ ранее открыт в других исследованиях; не считать новой нетронутой выборкой. После отчёта решать дальнейшие гипотезы; не внедрять сигнал из reconstruction.
